Engineered for Velocity

Precision Design Protocol

The RaceCraft Design System is a comprehensive technical framework for motorsport engineering interfaces. Built for high-density data environments where milliseconds define the edge of performance.

DESIGN PRINCIPLES

Core tenets that govern every pixel of the RaceCraft ecosystem.

settings_input_component

Engineering First

Functionality dictates form. We prioritize data fidelity and interaction speed over aesthetic decoration. If an element doesn't aid engineering insight, it's removed.

speed

Motion with Purpose

Animations are functional tools, not flourishes. Use linear easings and rapid durations to reflect the high-frequency nature of telemetry streams.

visibility

Clarity Over Complexity

In high-stress pit lane environments, cognitive load is our enemy. We use clear visual hierarchies and monospaced data for instant legibility.

IBM Plex Sans (Body)

Weight: 400 / Leading: 1.6

Documentation and explanatory text uses IBM Plex Sans to ensure high readability for long-form content. This serif-free typeface maintains the technical aesthetic while providing better contrast for descriptive paragraphs compared to condensed UI fonts.

Chart Standards

  • Stroke width: strictly 1.5pt to 2pt.

MOTION PRINCIPLES

Linear precision for rapid feedback.

Fast (Micro-feedback) 100ms
Standard (Panel Exit) 200ms

Curve Protocol: cubic-bezier(0.2, 0.0, 0, 1.0) - Linear-style start with a rapid terminal decelerate.

VOICE & ACCESSIBILITY

The human side of engineering.

TONE: CONFIDENT & CLINICAL

"Fuel levels are within critical tolerances for 3 additional laps."

Avoid: "You're doing great, just keep going!"

ACCESSIBILITY: BEYOND COLOR

Every status indicator MUST have a unique icon companion. We never rely on color alone to communicate status (e.g., Brake vs Throttle line patterns).
